画 DRAM 时序图的地方。做 IC 设计的人大概都试过用 PowerPoint 画波形——拖出来一个方框，复制八个，改一下时刻发现全歪了。PPT 有形状，没有「边沿」这个概念；而时序图里真正重要的恰恰是边沿在什么时刻、每段保持什么值。

这个工具就干一件事：**让你改数据，而不是画图**。波形是算出来的，不是拖出来的。

## 四种信号

- **数字** —— 由边沿列表决定。0/1 之间是直角台阶，没有斜线（时序图里的斜线是错的）
- **时钟** —— 参数化：填周期、占空比、相位，边沿自动重算。改 tCK 不用逐个沿去改
- **总线** —— 按时段显示十六进制，段间画标准 X 交叉。X 的半宽受相邻段长度约束，短段不会把邻居的电平盖住
- **模拟** —— 折线 + 关键点圆标，用来看电源轨和模拟前端的时序关系

## 交互

拖边沿改时刻 · 点电平翻转 · 双击总线段加一 · 方向键微调 1 格（Shift 加速）· 全部改动可撤销

**吸附**默认开着。拖边沿时会优先吸到已有游标、时钟沿、其它信号的边沿，其次吸网格——画 DDR 时序最花时间的就是让一堆边沿对齐到同一个时钟沿，手动拖是折磨。

标注用竖直游标 + 双向箭头 + 参数名。tRCD、tCL、tRP、tWR 这些 JEDEC 里的时序参数就是用它标的。

## DRAM 预设

按 JEDEC 各时序参数的定义做了典型值，**重点是给个合理起点，不是 datasheet**：

- **DDR3 读突发 BL8** —— ACT → tRCD → READ → tCL → tRP → PRE 全链
- **DDR4 写突发 BL16** —— 写 DQS 定位与 tWR 恢复窗口
- **DRAM 刷新占用** —— tRC / tRFC / tREFI，说明刷新为什么吃带宽
- **Bank 冲突与行命中** —— 行缓冲命中与否的代价对比

另有上电复位、同步 FIFO、SPI、I²C、UART、JTAG 六个通用预设。

## 导出才是终点

**SVG 是核心输出。** 导出时所有样式写成 presentation attribute，**不含 `<style>` 块、不用 CSS class、不引用外部资源** —— 这样 .svg 文件拖进 PowerPoint、Figma、Illustrator 都不会因为找不到样式而变成一团黑。矢量在 PPT 里放大不失真，缩到一页 A4 塞进文档也没问题。

PNG 走 2 倍分辨率，透明/白底可选。另有 JSON 导入导出做备份分享。

## 几个技术选择

**时间用整数 tick，不存浮点秒。** 免掉 0.1+0.2 的精度问题，也避免导出 SVG 时出现 `17.999999` 这样的坐标。真实时间由 `tickNs` 换算，显示时统一截断浮点尾数。

**时钟是参数化的，不是展开成边沿存的。** 展开也能画，但改周期就得逐个沿改。参数驱动才能让「改 tCK 整条波形一起动」。

**每条信号输出一条 path**，复杂度 = 跳变次数而非时间点数。50 条沿 × 20 信号只有 20 个 path 元素，PNG 导出时也少写一堆坐标。

**纯逻辑层不碰 DOM**，`src/lib/timing/` 下的 model / render / preset 全是无依赖纯函数，**204 条断言**覆盖时间换算、时钟展开与电平一致性、边沿编辑不变量、总线掩码与 X 交叉半宽、吸附优先级、撤销栈、脏数据归一化、ID 唯一性、导出自包含性。用 esbuild bundle 后交给 node 直接跑，出错时读断言比在页面上猜快得多。

**验收用真实浏览器派发鼠标事件**，不只测静态布局——拖边沿、点翻转、改周期、改总线值、撤销重做、导出 SVG/PNG、刷新恢复、键盘微调、亮暗模式，**61 项全过**。其中包括「每行信号名与波形严格对齐（偏差 ≤2px）」这种纯靠截图看不出来的断言。

## 踩过的坑

写这个工具时抓到的几个问题记在这里，因为它们都属于「不报错但行为是错的」那一类：

- **接口 import 必须带 `type` 修饰符。** Vite dev 下 esbuild 逐文件转译，`import { AnalogSeg }`（接口）会原样留成运行时具名导入，浏览器直接抛 `does not provide an export named`。而 `tsc` 单文件检查时把整个文件当整体，压根看不出问题。
- **拖拽曾完全无法撤销。** `beginDrag()` 写在 `this.drag = {...}` 之前，而它有 `if (!this.drag) return` 守卫，于是历史栈永远不进东西——症状是「拖完点撤销，整张图回到载入预设之前」。
- **`data-el` 必须全局唯一。** 名字列容器和「信号名」复选框都用过 `data-el="names"`，`querySelector` 取到先出现的那个，132px×294px 的样式被打在了复选框上，工具栏中间浮着一个巨大的蓝色对勾方块。现在构造时会校验重复并抛错。
- **预设 ID 与运行时 ID 曾撞车**，导致「删一条信号，少了两条」。修法是预设 ID 加 `p` 前缀隔离命名空间 + `removeSignal` 改成只删第一条。
